## Project overview

Minimal demo used by **agent-sync** to show one-source multi-target sync.
Not a real application — edit this file, then run `agent-sync apply`.

## Toolchain

| Intent | Command | Notes |
|--------|---------|-------|
| Install | `npm install` | No deps in this demo |
| Test agent-sync | `npm test` | Run from agent-sync repo root |
| Apply rules | `agent-sync apply` | Regenerates tool files |

## Judgment boundaries

### ASK before

- Deleting files or directories
- Changing public APIs

### ALWAYS

- Prefer editing existing files over creating new ones
- Keep diffs focused on the requested task

### NEVER

- Commit secrets or credentials
- Invent APIs or paths that do not exist
